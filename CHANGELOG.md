# Change Log

All notable changes to the "threadlens" extension will be documented in this file.

## [0.0.2] - Optimization & Fixes

- 📦 Massively reduced extension bundle size (from 23MB down to ~280KB).
- 🛠️ Fixed internal compatibility with newer VS Code APIs.

## [0.0.1] - Initial Release

- Initial release of ThreadLens.
- Support for loading and parsing Java thread dumps (`.tdump`, `.threaddump`, `.log`).
- Ability to load uncompressed thread dumps or `.zip` archives.
- Tree view for loaded thread dumps with file icons.
- Built-in deadlock detection.
- Optional AI-powered thread dump analysis using OpenAI.
